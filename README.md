# 🎓 Admission Predictor

This project predicts whether a student is likely to be admitted to a university using logistic regression.

📁 Files
- `admission_predictor.ipynb` – Main Jupyter Notebook
- `README.md` – Project overview

 📊 Features Used
- GRE Score
- TOEFL Score
- CGPA
- SOP & LOR strength
- Research Experience
- University Rating

 ML Model
- **Logistic Regression** (binary classifier)
- Evaluated with:
  - Accuracy
  - Confusion Matrix
  - Precision, Recall, F1-Score
  - ROC-AUC Score

🧪 Dataset
- Source: [Graduate Admissions Dataset – Kaggle](https://www.kaggle.com/datasets/mohansacharya/graduate-admissions)

🚀 How to Run
1. Clone this repo or download the `.ipynb` file
2. Run it in Jupyter Notebook or Google Colab
3. Modify inputs to predict admission results
